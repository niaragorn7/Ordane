# Ordane V2

V2 expands the core quote-to-order workflow with richer commercial and operational capabilities.

## Proposed Scope

- Pricing and price lists
- Customer-specific pricing
- Advanced pricing rules
- Automated approval workflows
- Quote revisions and versioning
- Multiple Orders per Quote
- Partial order fulfillment
- Operational audit history
- Asynchronous processing

## Goal

Expand the core B2B order-management capabilities while keeping the existing architecture coherent.
